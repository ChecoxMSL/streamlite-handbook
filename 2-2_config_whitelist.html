⚙️ Penalties, Whitelist & SP Tier

This page covers three configuration areas that the Administrator manages: Penalty Rules, the Full Bonus Whitelist, and SP Comercial Tier agents. All three are environment-aware — changes in SANDBOX do not affect PROD.

1. Edit Penalty Rules

Penalty rules control how many stars are deducted when a QA agent flags infractions during grading. Rules are stored in the Admin_Config sheet and loaded dynamically by every QA session.

1.1 How to Edit

  1. Open ⚙️ Admin Settings → expand ⚖️ Edit Penalty Rules.
  2. For each infraction category, adjust two values:
    • Stars Deduction — how many stars are subtracted (0.0 to 5.0, in 0.5 increments).
    • Evidence Needed — how many flagged calls are required before the penalty kicks in (1 to 20).
  3. Click 💾 Save Business Rules.

1.2 Default Penalty Reference

Infraction Default Deduction Default Threshold
Call Avoidance−1.0 ★≥ 1 flagged call
Wrong Disposition−1.0 ★≥ 3 flagged calls
Script Violation−1.0 ★≥ 3 flagged calls
Tone / Attitude−1.0 ★≥ 1 flagged call
Other−1.0 ★≥ 1 flagged call
💡 How It Works: For each category, if the QA agent's flagged count meets or exceeds the threshold, the deduction is applied. Below the threshold = no penalty. Changes apply immediately to new gradings only — existing audits are not retroactively affected.
⚠️ Real-Time Sync: Penalty rules are shared across all active QA sessions. When you save changes, every QA agent will see the updated rules immediately on their next action.

2. Full Bonus Whitelist

Agents on the whitelist automatically receive a 5-star Full Bonus Certificate — they bypass the BigQuery call review entirely. Use this for agents who are pre-approved for full bonus based on their performance level.

2.1 How to Manage

  1. Open ⚙️ Admin Settings → expand ⭐ Full Bonus Whitelist.
  2. Use the multiselect widget to pick agents from the pending list.
  3. Click 💾 Save Whitelist.

2.2 Whitelist Lead Threshold (whitelist_target_leads)

Being on the whitelist alone is not enough — the agent must also meet a minimum lead count for the week. This threshold is stored in the App_Config sheet under the key whitelist_target_leads (default: 18 leads, same as the standard threshold).

Condition Result
On whitelist AND leads ≥ whitelist_target_leads ⭐ Full Bonus Certificate — bypasses BQ review
On whitelist BUT leads < whitelist_target_leads Routed to normal grading (standard QA Report Card flow)
💡 Changing the Threshold: To adjust the minimum leads required for whitelist agents, edit the whitelist_target_leads value directly in the App_Config tab of the RAW_DB spreadsheet. The change takes effect on the next session load — no code deploy needed.

2.3 What Happens When You Save

  • Newly added agents (who meet the threshold) → marked with stars: 5.0 and full_bonus_granted: True. They appear in the sidebar with ⭐ and are ready for PDF generation.
  • Removed agents → reverted to ⚪ pending only if no PDF has been generated yet. If a PDF already exists, use Ledger & Cleanup to remove the record manually.
⚠️ Whitelist persists across weeks. Unlike the audit ledger (which resets weekly), the whitelist stays active until you manually remove agents. Review it at the start of each grading cycle.

3. SP Comercial Tier

Agents flagged as SP Comercial Tier eligible receive a Full Bonus Certificate if they reach the lead threshold (default: 45 leads). This is independent of the whitelist — it's a performance-based qualification.

3.1 How to Manage

  1. Open ⚙️ Admin Settings → expand 🏆 SP Comercial Tier Agents.
  2. Use the multiselect widget to select eligible agents.
  3. The current lead threshold is displayed (e.g., "Lead threshold: 45 leads").
  4. Click 💾 Save SP Tier List.
💡 Lead Threshold: The threshold value (default 45) is stored in the App_Config sheet. To change it, edit the sp_tier_target value directly in the RAW_DB spreadsheet — it is not editable from the sidebar.

3.2 How SP Tier Works at Grading Time

  • When a QA agent grades an SP Tier-eligible agent, the system checks if the agent's lead count ≥ threshold.
  • If yes → the agent receives a Full Bonus Certificate (same as whitelist), marked with ⭐ in the sidebar.
  • If no → the agent is graded normally (standard Report Card or Suspension Banner).

Quick Reference

⚖️ Penalty Rules

Stored in Admin_Config. Real-time sync. Affects new gradings only.

⭐ Whitelist

Stored in Whitelist_Config. Persists across weeks. Bypasses BQ review. Requires whitelist_target_leads (App_Config) to grant Full Bonus.

🏆 SP Tier

Stored in SP_Tier_Config. Conditional on lead count. Threshold in App_Config.
