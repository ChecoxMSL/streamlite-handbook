📚 Audit History & Reference

This page covers the week slot system, how audit records are automatically archived, and provides quick-reference tables for common operations.

1. Week Slot Format

Every audit record is tied to a week slot — a fixed Monday-to-Sunday date range in MM/DD-MM/DD format. This ensures records are permanently tied to the production week they belong to.

Example Week Slots

SlotMeaning
03/09-03/15Previous week (Mon Mar 9 → Sun Mar 15)
03/16-03/22Current week (Mon Mar 16 → Sun Mar 22)
03/23-03/29Next week (Mon Mar 23 → Sun Mar 29)
💡 Automatic Computation: Week slots are computed automatically by the app. You never need to enter dates manually. The system always uses the Monday-Sunday range regardless of which day the grading is performed.

2. Automatic Archival Process

When a new session starts, the app checks for old week slots in the Audit_Ledger. Slots older than "Last Week" are automatically archived. This process is completely silent — no notification is shown.

1. Session Starts

The function auto_archive_old_slots() runs silently on every session init.

2. Old Slots Identified

Any week slot older than "Last Week" is marked for archival. Current Week and Last Week remain active.

3. Records Written to History

All agent records from old slots are appended to Audit_History (permanent, never edited).

4. Old Records Removed from Ledger

Archived rows are deleted from Audit_Ledger, leaving only current and last week data.

2.1 History Panel — Browsing Past Weeks

Any QA user can browse archived weeks using the 📚 History tab in the main app area. The History panel is read-only — no data can be modified.

5. Concurrency & Multi-User Access

The app supports up to 5 QA agents working simultaneously. Each QA agent is typically assigned a different set of agents to grade, so conflicts are rare.

  • The ledger uses a last-write-wins strategy for same-agent edits.
  • Since QA agents work on different agents, concurrent conflicts are unlikely.
  • The environment toggle is global — switching affects everyone immediately.
⚠️ Coordinate Before Switching: If you need to toggle the environment, make sure no other QA agent is actively grading. The switch is instant and affects all sessions.
