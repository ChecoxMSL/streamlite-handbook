📄 Understanding Grading Outputs

When you click Generate, the system evaluates the agent's score and type, then automatically selects the correct output format. You don't choose the format manually — the logic is handled for you.

2.3 Output Format Decision Table

The system applies this logic in order every time you generate a result:

Condition Output Generated Format
Agent is marked Suspended 🚫 🛑 Suspension Banner PNG — 800×340px, dark theme
Agent scores 5 ★ (no deductions) 🏆 Full Bonus Certificate PDF — Landscape A4
Agent is on the Admin Whitelist 🏆 Full Bonus Certificate PDF — Landscape A4
Agent qualifies for SP Comercial Tier (45+ leads) 🏆 Full Bonus Certificate PDF — Landscape A4
Agent scores < 5 ★ and is not on any special list 📄 Standard Report Card PDF — Portrait A4, dark theme
💡 Note: Suspension takes priority over everything else. If an agent is flagged as 🚫 Suspended, a Banner is always generated — regardless of their lead count or whitelist status.
< 5 ★ — Standard

📄 QA Bonus Report Card

Portrait A4 PDF with dark theme. Includes call scores, penalty breakdown, qualitative feedback, and the recording link table with gold play icons.

5★ / Whitelist / SP Tier

🏆 Full Bonus Certificate

Landscape A4 PDF with the branded certificate background. Awarded automatically — no special action required from you.

Suspended 🚫

🛑 Suspension Banner

Dark-theme PNG (800×340px). Generated using Pillow — no PDF involved. Still gets uploaded to Drive and dispatched by the Administrator.

📄 Standard Report Card (PDF)

Used for agents scoring less than 5 stars. Contains the full penalty breakdown so the agent can see exactly what was deducted and why.

🏆 Full Bonus Certificate (PDF)

Awarded when an agent achieves a perfect score (5★), appears on the Administrator's whitelist, or qualifies under SP Comercial Tier (45+ leads). The system identifies all three cases automatically.

🛑 Suspension Banner (PNG)

Generated for agents marked Suspended. The banner is uploaded to the same Google Drive folder structure as other outputs and is dispatched by the Administrator via Google Chat.

📁 Where do the files go? All generated files are automatically uploaded to the correct Google Drive subfolder by office and week. You do not need to upload anything manually. See the next page for folder structure details.
