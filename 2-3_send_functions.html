🚀 Send Functions

After all QA agents have completed their grading (all agents are 🟣 Purple), the Administrator completes the final two steps: HR Sync and Google Chat Dispatch. These must be done in order.

🟣 PDF Generated QA Agent completes grading
→
🔵 HR Sync Admin pushes to HR Sheet
→
🟢 Chat Dispatch Admin sends via Google Chat
🚨 Order Matters: You must run HR Sync before Chat Dispatch. The system enforces this — agents in 🟣 status cannot be dispatched via Chat until they are first synced to the HR Spreadsheet (🔵).

1. Stage 1 — HR Spreadsheet Sync (🟣 → 🔵)

This step pushes the audit results from the internal ledger to the HR Spreadsheet so the HR department has a record of each agent's bonus qualification.

1.1 How to Run

  1. Open Admin Settings → expand 🚀 Send Functions.
  2. Review the pending counts displayed at the top: "Pending: X → HR Sheet (🟣) | Y → Chat (🔵)".
  3. Click 📊 Send QA Bonus to HR Spreadsheet.
  4. The system processes each 🟣 agent and writes a row to the HR Spreadsheet.

1.2 What Gets Written to the HR Spreadsheet

For each agent, the system inserts a row with:

Column Content
TimestampDate and time of the sync (YYYY-MM-DD HH:MM:SS)
Agent NameFull agent name as it appears in the sidebar
QA StarsFinal star rating (e.g., "4.0 ★")
CashCash conversion calculated from stars
QA AgentName of the QA agent who performed the grading
💡 Week Organization: If this is the first sync for the current week, the system automatically creates a week label row (e.g., "03/16-03/22 (Week 12)") and a header row in the HR Spreadsheet before inserting agent rows. This keeps the spreadsheet organized by week.
✅ After Sync: Agent labels in the sidebar turn from 🟣 Purple to 🔵 Blue. The confirmation message shows: "✅ X agent(s) synced to HR under 'MM/DD-MM/DD'."

2. Stage 2 — Google Chat Dispatch (🔵 → 🟢)

This step sends each agent their individual QA Bonus result via Google Chat DM. The message includes a link to their PDF (Report Card, Certificate, or Suspension Banner) stored in Google Drive.

2.1 How to Run

  1. In 🚀 Send Functions, scroll to the 📤 Send PDF Preview via Google Chat section.
  2. Verify the current mode is displayed: 🟢 PROD or 🟡 SANDBOX.
  3. Review the list of agents with PDFs ready to dispatch.
  4. Click 📨 Send PDF Cards via Google Chat.
  5. The system sends a DM to each agent with their PDF link.

2.2 Message Content

🟢 PROD Message

"Good day {Agent Name}, here is your QA Bonus Report Card for this week:

📄 [PDF Link]

For any questions contact your supervisor."

Sent to the agent's real email.

🟡 SANDBOX Message

"[SANDBOX — To: {Agent Name} ({email})]

Good day {Agent Name}, here is your QA Bonus Report Card...

📄 [PDF Link]"

Sent to the test email only.

2.3 Throttling & Rate Limits

The system applies a 1.5-second delay between each message to prevent Google Chat API rate limiting. For large batches (e.g., 30+ agents), the dispatch may take a couple of minutes to complete.

✅ After Dispatch: Agent labels turn from 🔵 Blue to 🟢 Green 🏁. Confirmation: "✅ X PDF(s) sent to [target]. Errors: Y". If any errors occurred, they are listed individually.

3. Special Dispatch Cases

3.1 Full Bonus Agents (⭐ Whitelist / SP Tier)

Full Bonus agents skip the 🔵 step — they go directly from 🟣 to 🟢. When you run Chat Dispatch, these agents are included alongside the 🔵 agents.

3.2 Suspended Agents (🚫)

Suspended agents still receive a Chat dispatch. Instead of a Report Card, the message contains a link to their Suspension Banner (PNG).

3.3 Error Handling

  • If the agent's email cannot be resolved, the dispatch for that agent fails and is reported in the summary.
  • If Google Chat API returns an error, the system logs it and continues with the remaining agents.
  • Failed agents can be retried by running Chat Dispatch again — only unsent agents are processed.
⚠️ Link Unfurling: For the PDF link to show a preview in Google Chat, the Drive file must have "Anyone with the link" permission. The app sets this automatically when uploading — no manual action needed.
