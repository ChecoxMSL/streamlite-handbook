🔁 Re-grade, Ledger & Cleanup

This page covers corrective actions: resetting an agent's grade, editing ledger entries, resetting the entire week, and cleaning up local files.

1. Re-grade Agent

The Re-grade function resets an already-audited agent back to ⚪ pending so a QA agent can redo the audit. This is available to all QA users (not just admins) from the sidebar.

⚠️ Accountability: Every re-grade action is logged in the QA_Activity_Log sheet with the timestamp, the QA user who initiated it, and the agent name. This is an audit trail — use re-grade only when genuinely needed.

1.1 How to Re-grade

  1. In the sidebar, expand 🔁 Re-grade Agent.
  2. Use the search filter to find the agent (e.g., type "garcia", "sp", "a m").
  3. Select the agent from the dropdown.
  4. A confirmation card appears showing:
    • Agent name
    • Current status (🟣 Audited or 🔵 Synced)
    • Current star rating
    • Week slot
  5. Click 🔁 Reset to pending.
  6. The agent returns to ⚪ and can be graded again.

1.2 Restrictions

The following agents cannot be re-graded:

Agent Type Reason
🚫 SuspendedAutomatic disqualification — cannot be overridden via re-grade
⭐ WhitelistedFull bonus is admin-configured — remove from whitelist instead
⭐ SP TierPerformance-based qualification — remove from SP Tier list instead
💡 Tip: If a whitelisted or SP Tier agent needs correction, first remove them from the respective list (Whitelist or SP Tier panel), then re-grade if needed.

2. Ledger & Cleanup

The 🗑️ Ledger & Cleanup section in Admin Settings provides manual control over the audit ledger. Use this for fixing state errors or performing week-level resets.

2.1 Edit / Remove Individual Agent

  1. Use the search box to find an agent.
  2. Select the agent from the dropdown.
  3. The current state is displayed with editable checkboxes:
    • Synced (HR) — whether the agent has been synced to the HR Spreadsheet.
    • Sent (Chat) — whether the agent has been dispatched via Google Chat.
  4. Choose an action:
    • 💾 Save Changes — updates only the synced/sent flags in the ledger.
    • 🗑️ Remove Agent — completely deletes the agent's record from this week's ledger.
💡 Use Case: If an agent was accidentally synced to HR but shouldn't have been, you can uncheck "Synced (HR)" and save. This resets them to 🟣 so you can re-sync after correcting the issue.

2.2 Full Week Reset

🚨 Destructive Action: This permanently clears all agent records for the active week. There is no undo. Use only when you need to start the entire week's grading from scratch.
  1. In 🗑️ Ledger & Cleanup, note the active week displayed (e.g., "Active week: Mar 16th to Mar 22nd").
  2. Click 🗑️ Reset Entire [Week] Ledger.
  3. All agent records for that week are wiped — everyone returns to ⚪ pending.

2.3 Local Files Cleanup

PDFs are automatically deleted from the server after upload to Google Drive. In edge cases where local files remain, this section lets you clean them up manually.

  1. The panel shows a count of local PDF files on the server.
  2. Click 🗑️ Delete All Local PDFs.
  3. Files are deleted from the server only — Google Drive copies are unaffected.
💡 Safe Operation: Since all PDFs are already uploaded to Google Drive before reaching this point, deleting local copies has no impact on the stored records or links shared with agents.
