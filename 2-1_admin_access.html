🔑 Admin Access & Environment

This section covers how to unlock Admin Mode, what features become available, and how the PROD / SANDBOX environment system works. Admin access is required for all operations described in this chapter.

⚠️ Admin Only: Everything in this chapter requires the Admin PIN. Regular QA agents do not have access to these features. If you are a regular QA agent, refer to Chapter 1 — QA Agent Guide.

1. Unlocking Admin Mode

1.1 Where to Find It

Admin Settings is located in the sidebar, below the Audit Progress List. Look for the ⚙️ Admin Settings expander.

  1. Expand the ⚙️ Admin Settings section in the sidebar.
  2. Enter the Admin PIN in the input field.
  3. Once the correct PIN is entered, all admin features will unlock immediately.
✅ Admin Mode Unlocked — You will see a green confirmation message. All admin panels (Penalty Rules, Send Functions, Whitelist, SP Tier, Ledger & Cleanup) become visible.

1.2 What Unlocks

Once admin mode is active, the following panels appear inside the Admin Settings expander:

Panel Purpose
⚖️ Edit Penalty RulesAdjust star deductions and evidence thresholds for each infraction category
🚀 Send FunctionsHR Spreadsheet sync and Google Chat dispatch
⭐ Full Bonus WhitelistMark agents for automatic full bonus (bypasses grading)
🏆 SP Comercial TierFlag agents eligible for SP Tier bonus (45+ leads)
🗑️ Ledger & CleanupReset week, edit/remove individual agents, delete local files
🌍 Environment ToggleSwitch between PROD and SANDBOX

2. PROD vs SANDBOX Environment

The app operates in one of two environments at all times. A single toggle in Admin Settings controls which environment is active. The environment is global — switching it affects all QA agents currently using the app.

🟢 PROD (Production)

  • All data writes go to live Sheets tabs
  • HR Sync pushes to the real HR Spreadsheet
  • Chat dispatch sends to real agent emails
  • Audit Ledger: Audit_Ledger
  • Admin Config: Admin_Config
  • Whitelist: Whitelist_Config
  • SP Tier: SP_Tier_Config

🟡 SANDBOX (Testing)

  • All data writes go to isolated sandbox tabs
  • HR Sync still works but writes to sandbox tab
  • Chat dispatch sends to test email only
  • Audit Ledger: Audit_Ledger_Sandbox
  • Admin Config: Admin_Config_Sandbox
  • Whitelist: Whitelist_Config_Sandbox
  • SP Tier: SP_Tier_Config_Sandbox
💡 Key Rule: PROD data is never affected by SANDBOX activity. The two environments are completely isolated. Sandbox tabs are auto-created the first time you switch to SANDBOX.

2.1 How to Switch Environments

  1. Open ⚙️ Admin Settings in the sidebar.
  2. Find the Environment section.
  3. Toggle the switch to SANDBOX or PROD.
  4. The app will immediately reload all data from the target environment's Sheets tabs.
🚨 Important: Switching the environment affects all active QA sessions. If other QA agents are currently grading, coordinate with them before switching. Always switch back to PROD when you finish testing.

2.2 When to Use SANDBOX

  • Training new QA agents — let them practice grading without affecting real data.
  • Testing penalty rule changes — verify new thresholds before applying to production.
  • Testing Send Functions — confirm HR sync and Chat dispatch work correctly without sending to real agents.
  • Debugging issues — reproduce problems in an isolated environment.
